# Buzzword Family Bee

A pass-the-tablet family spelling bee. Players sit in a circle. The next player reads each word, its meaning, and a sentence, and the speller spells it out loud. Two misses and you're out, and the words get harder as players drop out. Everyone plays at their own level (Little Bees, Busy Bees, Honey Masters, Queen Bees).

Play it: https://austinberezniak32.github.io/family-spelling-bee/

Install on a tablet: open the link in Chrome, tap the ⋮ menu, then **Add to home screen** (or **Install app**). After the first open it works offline.

When you change files, bump `VERSION` in `sw.js` so installed copies pick up the update.
